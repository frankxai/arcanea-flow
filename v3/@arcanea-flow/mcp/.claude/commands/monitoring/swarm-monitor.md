# swarm-monitor

Real-time swarm monitoring.

## Usage
```bash
npx arcanea-flow swarm monitor [options]
```

## Options
- `--interval <ms>` - Update interval
- `--metrics` - Show detailed metrics
- `--export` - Export monitoring data

## Examples
```bash
# Start monitoring
npx arcanea-flow swarm monitor

# Custom interval
npx arcanea-flow swarm monitor --interval 5000

# With metrics
npx arcanea-flow swarm monitor --metrics
```
